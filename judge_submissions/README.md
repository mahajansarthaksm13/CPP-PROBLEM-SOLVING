# Judge-format submissions

The topic folders hold standalone programs that read from `stdin` and write to
`stdout` — the form CodeChef accepts and the form the course expects.

LeetCode and GeeksforGeeks do not take whole programs. They supply a driver and
expect only a class body with a fixed signature, different for every problem.
The files here are the same algorithms rewritten to those signatures, kept
separate so the topic folders stay in the course's format.

| Folder | Judge | Problems | Result |
|--------|-------|----------|--------|
| `leetcode/` | LeetCode | 9 | all Accepted |
| `geeksforgeeks/` | GeeksforGeeks | 66 | all Accepted |

Every file here was submitted to its judge and returned a passing verdict.
